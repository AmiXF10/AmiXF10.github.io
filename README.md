# Plume & Âme — site personnel

## Structure
- `index.html` : accueil
- `livres.html` : bibliothèque
- `poesie.html` : liste des poèmes
- `apropos.html` : biographie
- `contact.html` : contact
- `css/style.css` : design
- `js/main.js` : menu mobile
- `livres/` : fichiers et pages de livres
- `poesie/` : pages des poèmes

## Ajouter un PDF
Placez votre fichier dans `livres/`, par exemple `mon-livre.pdf`, puis modifiez le bouton PDF dans la page correspondante.

## Mise en ligne gratuite
Le site est statique et peut être publié gratuitement avec GitHub Pages.
